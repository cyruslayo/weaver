## Message rules

- Output A2UI v1.0 messages as JSON Lines: one complete JSON object per line, with no prose and no code fences.
- Every message has `"version": "1.0"` and exactly one of `createSurface`, `updateComponents`, `updateDataModel` or `deleteSurface`.
- `createSurface` takes `surfaceId` and `catalogId`. The `catalogId` must equal one of these catalog ids: "https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json". It may also carry an initial `components` array and an initial `dataModel` object; the data model is applied first.
- `updateComponents` takes `surfaceId` and `components`. Components are flat objects. Each has a unique `id` and a `component` name from the catalog. Refer to children by id.
- Component ids must be UAX #31 identifiers: start with a letter or an underscore, continue with letters, digits or underscores, and never start with a digit. Hyphens, spaces and other symbols are not allowed. `user_card` and `userCard` are valid; `user-card` and `1st_item` are not.
- The component tree is rooted at the component with id `"root"`.
- A container's `children` property is either an array of component ids, or a template object `{"componentId": "<id>", "path": "/json/pointer"}`. The template `path` is a plain string, not a binding. One child is built for each item of the array at that path.
- Inside a template, a path that does not start with `/` is relative to the current item: `"name"` reads `name` from that item. A path that starts with `/` is absolute. `{"@call": "@index"}` returns the 0-based index of the current item.
- Bindings: `{"@path": "/json/pointer"}` reads the data model. `{"@call": "<name>", "args": {...}}` calls a catalog function. To use a literal key that starts with `@`, double the `@` (`"@@path"` means `"@path"`).
- `formatString` builds text from `${...}` expressions, for example `{"@call": "formatString", "args": {"value": "Hello ${/user/name}"}}`. Write a literal `${` as `\${`.
- `Text` supports simple Markdown. Write a heading as a Markdown heading such as `## Order shipped`. The `variant` of `Text` is only `caption` or `body`.
- Checkable components (inputs and buttons) accept `@checks`: a list of `{"condition": <binding or function call>, "message": "<text>"}`. A condition yields a boolean or a ValidationResult. `message` is the error text shown when the check fails.
- Components accept `@accessibility` with `label`, `description`, `live` (`"off"`, `"polite"` or `"assertive"`) and `hidden`. `label` and `description` are dynamic strings and `hidden` is a dynamic boolean.
- `updateDataModel` takes `surfaceId`, `path` (a JSON Pointer such as `"/form/name"`) and `value`. `value` is required. Set `value` to `null` to delete the key at `path`.
- `deleteSurface` takes `surfaceId`.

## Catalog instructions

Catalog `https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json`

For layout, use the Row and Column components to organize other components.

### Catalog Guidelines

1. String Concatenation & Formatting: A2UI does not support binary operators like '+' or formatting symbols. To concatenate strings or dynamically inject data bindings into text, you must use the catalog function `formatString(value)` where the value string contains placeholders formatted as `${expression}`:
   formatString("Hello ${/user/name}")

2. Strict Hierarchy: You must strictly adhere to the requested component nesting and hierarchy. If the prompt specifies that a component is 'inside' or 'contained in' another component, you MUST place it as a child of that specific component, not as a sibling or in a different container.

3. Validation Checks: When components support validation checks, specify any custom error messages directly as the 'message' inside the check. Do NOT create separate text-display components to display validation errors.

### Examples

Example 1: Dynamic text form
```json
[
  {
    "version": "1.0",
    "createSurface": {
      "surfaceId": "main",
      "catalogId": "https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json",
      "components": [
        {
          "id": "root",
          "component": "Column",
          "children": ["repField", "valueField"]
        },
        {
          "id": "repField",
          "component": "TextField",
          "label": "Representative",
          "value": {"@path": "/form/rep"},
          "placeholder": "Enter name"
        },
        {
          "id": "valueField",
          "component": "TextField",
          "label": "Deal Value",
          "value": {"@path": "/form/value"},
          "placeholder": "0.00",
          "variant": "number",
          "@checks": [
            {
              "condition": {
                "@call": "required",
                "args": {"value": {"@path": "/form/value"}}
              },
              "message": "Deal value is required."
            }
          ]
        }
      ],
      "dataModel": {
        "form": {
          "rep": "John Doe",
          "value": 1500.00
        }
      }
    }
  }
]
```

Example 2: Dynamic list with templates
```json
[
  {
    "version": "1.0",
    "createSurface": {
      "surfaceId": "main",
      "catalogId": "https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json",
      "components": [
        {
          "id": "root",
          "component": "Card",
          "child": "breedList"
        },
        {
          "id": "breedList",
          "component": "List",
          "children": {
            "path": "/breeds",
            "componentId": "breedTemplate"
          },
          "direction": "horizontal"
        },
        {
          "id": "breedTemplate",
          "component": "Image",
          "url": {"@path": "url"}
        }
      ],
      "dataModel": {
        "breeds": [
          {
            "url": "https://example.com/poodle.jpg"
          },
          {
            "url": "https://example.com/lab.jpg"
          }
        ]
      }
    }
  }
```

## Components

Properties marked "binding allowed" accept a literal value, a data binding such as {"@path": "/json/pointer"}, or a function call such as {"@call": "<name>", "args": {...}}, as the property schema allows.

Catalog `https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json`

### AudioPlayer
- `component`: const "AudioPlayer"; required.
- `description`: string; optional; binding allowed. A description of the audio, such as a title or summary.
- `url`: string; required; binding allowed. The URL of the audio to be played.
- `weight`: reference Weight; optional.

### Button
- `@checks`: array of reference CheckRule; optional. A list of validation check rules to perform on the component.
- `action`: reference Action; required.
- `child`: reference Child; required. The ID of the child component. Use a 'Text' component for a labeled button. Only use an 'Icon' if the requirements explicitly ask for an icon-only button.
- `component`: const "Button"; required.
- `variant`: string; optional; enum "default", "primary", "borderless". A hint for the button style. If omitted, a default button style is used. 'primary' indicates this is the main call-to-action button. 'borderless' means the button has no visual border or background, making its child content appear like a clickable link.
- `weight`: reference Weight; optional.

### Card
- `child`: reference Child; required. The ID of the single child component to be rendered inside the card. To display multiple elements, you MUST wrap them in a layout component (like Column or Row) and pass that container's ID here. Do NOT pass multiple IDs or a non-existent ID.
- `component`: const "Card"; required.
- `weight`: reference Weight; optional.

### CheckBox
- `@checks`: array of reference CheckRule; optional. A list of validation check rules to perform on the component.
- `component`: const "CheckBox"; required.
- `label`: string; required; binding allowed. The text to display next to the checkbox.
- `value`: boolean; required; binding allowed. The current state of the checkbox (true for checked, false for unchecked).
- `weight`: reference Weight; optional.

### ChoicePicker
A component that allows selecting one or more options from a list.
- `@checks`: array of reference CheckRule; optional. A list of validation check rules to perform on the component.
- `component`: const "ChoicePicker"; required.
- `displayStyle`: string; optional; enum "checkbox", "chips". The display style of the component.
- `filterable`: boolean; optional. If true, displays a search input to filter the options.
- `label`: string; optional; binding allowed. The label for the group of options.
- `options`: array of object; required. The list of available options to choose from.
- `value`: string list; required; binding allowed. The list of currently selected values. This should be bound to a string array in the data model.
- `variant`: string; optional; enum "multipleSelection", "mutuallyExclusive". A hint for how the choice picker should be displayed and behave.
- `weight`: reference Weight; optional.

### Column
A layout component that arranges its children vertically. To create a grid layout, nest Rows within this Column.
- `align`: string; optional; enum "center", "end", "start", "stretch". Defines the alignment of children along the cross axis (horizontally). This is similar to the CSS 'align-items' property.
- `children`: reference ChildList; required. Defines the children. Use an array of strings for a fixed set of children, or a template object to generate children from a data list. Children cannot be defined inline, they must be referred to by ID.
- `component`: const "Column"; required.
- `justify`: string; optional; enum "start", "center", "end", "spaceBetween", "spaceAround", "spaceEvenly", "stretch". Defines the arrangement of children along the main axis (vertically). Use 'spaceBetween' to push items to the edges (e.g. header at top, footer at bottom), or 'start'/'end'/'center' to pack them together.
- `weight`: reference Weight; optional.

### DateTimeInput
- `@checks`: array of reference CheckRule; optional. A list of validation check rules to perform on the component.
- `component`: const "DateTimeInput"; required.
- `enableDate`: boolean; optional. If true, allows the user to select a date.
- `enableTime`: boolean; optional. If true, allows the user to select a time.
- `label`: string; optional; binding allowed. The text label for the input field.
- `max`: any; optional. The maximum allowed date/time in ISO 8601 format.
- `min`: any; optional. The minimum allowed date/time in ISO 8601 format.
- `value`: string; required; binding allowed. The selected date and/or time value in ISO 8601 format. If not yet set, initialize with an empty string.
- `weight`: reference Weight; optional.

### Divider
- `axis`: string; optional; enum "horizontal", "vertical". The orientation of the divider.
- `component`: const "Divider"; required.
- `weight`: reference Weight; optional.

### Icon
- `component`: const "Icon"; required.
- `name`: string or object or reference DataBinding; required; binding allowed. The name of the icon to display.
- `weight`: reference Weight; optional.

### Image
- `component`: const "Image"; required.
- `description`: string; optional; binding allowed. Accessibility text for the image.
- `fit`: string; optional; enum "contain", "cover", "fill", "none", "scaleDown". Specifies how the image should be resized to fit its container. This corresponds to the CSS 'object-fit' property.
- `url`: string; required; binding allowed. The URL of the image to display.
- `variant`: string; optional; enum "icon", "avatar", "smallFeature", "mediumFeature", "largeFeature", "header". A hint for the image size and style.
- `weight`: reference Weight; optional.

### List
- `align`: string; optional; enum "start", "center", "end", "stretch". Defines the alignment of children along the cross axis.
- `children`: reference ChildList; required. Defines the children. Use an array of strings for a fixed set of children, or a template object to generate children from a data list.
- `component`: const "List"; required.
- `direction`: string; optional; enum "vertical", "horizontal". The direction in which the list items are laid out.
- `weight`: reference Weight; optional.

### Modal
- `component`: const "Modal"; required.
- `content`: reference Child; required. The ID of the component to be displayed inside the modal.
- `trigger`: reference Child; required. The ID of the component that opens the modal when interacted with (e.g., a button).
- `weight`: reference Weight; optional.

### Row
A layout component that arranges its children horizontally. To create a grid layout, nest Columns within this Row.
- `align`: string; optional; enum "start", "center", "end", "stretch". Defines the alignment of children along the cross axis (vertically). This is similar to the CSS 'align-items' property, but uses camelCase values (e.g., 'start').
- `children`: reference ChildList; required. Defines the children. Use an array of strings for a fixed set of children, or a template object to generate children from a data list. Children cannot be defined inline, they must be referred to by ID.
- `component`: const "Row"; required.
- `justify`: string; optional; enum "center", "end", "spaceAround", "spaceBetween", "spaceEvenly", "start", "stretch". Defines the arrangement of children along the main axis (horizontally). Use 'spaceBetween' to push items to the edges, or 'start'/'end'/'center' to pack them together.
- `weight`: reference Weight; optional.

### Slider
- `@checks`: array of reference CheckRule; optional. A list of validation check rules to perform on the component.
- `component`: const "Slider"; required.
- `label`: string; optional; binding allowed. The label for the slider.
- `max`: number; required. The maximum value of the slider.
- `min`: number; optional. The minimum value of the slider.
- `steps`: integer; optional. The number of discrete divisions in the slider range. If specified, the slider will snap to discrete values.
- `value`: number; required; binding allowed. The current value of the slider.
- `weight`: reference Weight; optional.

### Tabs
- `component`: const "Tabs"; required.
- `tabs`: array of object; required. An array of objects, where each object defines a tab with a title and a child component.
- `weight`: reference Weight; optional.

### Text
- `component`: const "Text"; required.
- `text`: string; required; binding allowed. The text content to display. While simple Markdown formatting is supported (i.e. without HTML, images, or links), utilizing dedicated UI components is generally preferred for a richer and more structured presentation.
- `variant`: string; optional; enum "caption", "body". A hint for the base text style.
- `weight`: reference Weight; optional.

### TextField
- `@checks`: array of reference CheckRule; optional. A list of validation check rules to perform on the component.
- `component`: const "TextField"; required.
- `label`: string; required; binding allowed. The text label for the input field.
- `placeholder`: string; optional; binding allowed. The placeholder text for the input field.
- `value`: string; required; binding allowed. The value of the text field.
- `variant`: string; optional; enum "longText", "number", "shortText", "obscured". The type of input field to display.
- `weight`: reference Weight; optional.

### Video
- `component`: const "Video"; required.
- `posterUrl`: string; optional; binding allowed. The URL of the poster image to display before the video plays.
- `url`: string; required; binding allowed. The URL of the video to display.
- `weight`: reference Weight; optional.

## Functions

Only these functions may be called. No other function names are allowed.

- `and` returns boolean. Performs a logical AND operation on a list of boolean values.
  - `values`: arrayOfDynamicValues; required. The list of boolean values to evaluate.

- `email` returns validationResult. Checks that the value is a valid email address.
  - `value`: dynamicString; required.

- `formatCurrency` returns string. Formats a number as a currency string.
  - `currency`: dynamicString; required. The ISO 4217 currency code (e.g., 'USD', 'EUR').
  - `decimals`: dynamicNumber; optional. Optional. The number of decimal places to show. Defaults to 0 or 2 depending on locale.
  - `grouping`: dynamicBoolean; optional. Optional. If true, uses locale-specific grouping separators (e.g. '1,000'). If false, returns raw digits (e.g. '1000'). Defaults to true.
  - `value`: dynamicNumber; required. The monetary amount.

- `formatDate` returns string. Formats a timestamp into a string using a pattern.
  - `format`: dynamicString; required. A Unicode TR35 date pattern string.

Token Reference:
- Year: 'yy' (26), 'yyyy' (2026)
- Month: 'M' (1), 'MM' (01), 'MMM' (Jan), 'MMMM' (January)
- Day: 'd' (1), 'dd' (01), 'E' (Tue), 'EEEE' (Tuesday)
- Hour (12h): 'h' (1-12), 'hh' (01-12) - requires 'a' for AM/PM
- Hour (24h): 'H' (0-23), 'HH' (00-23) - Military Time
- Minute: 'mm' (00-59)
- Second: 'ss' (00-59)
- Period: 'a' (AM/PM)

Examples:
- 'MMM dd, yyyy' -> 'Jan 16, 2026'
- 'HH:mm' -> '14:30' (Military)
- 'h:mm a' -> '2:30 PM'
- 'EEEE, d MMMM' -> 'Friday, 16 January'
  - `value`: dynamicValue; required. The date to format.

- `formatNumber` returns string. Formats a number with the specified grouping and decimal precision.
  - `decimals`: dynamicNumber; optional. Optional. The number of decimal places to show. Defaults to 0 or 2 depending on locale.
  - `grouping`: dynamicBoolean; optional. Optional. If true, uses locale-specific grouping separators (e.g. '1,000'). If false, returns raw digits (e.g. '1000'). Defaults to true.
  - `value`: dynamicNumber; required. The number to format.

- `formatString` returns string. Performs string interpolation of data model values and other functions in the catalog functions list and returns the resulting string. The value string can contain interpolated expressions in the `${expression}` format. Supported expression types include: JSON Pointer paths to the data model (e.g., `${/absolute/path}` or `${relative/path}`), and renderer-side function calls (e.g., `${now()}`). Function arguments must be named (e.g., `${formatDate(value:${/currentDate}, format:'MM-dd')}`). To include a literal `${` sequence, escape it as `\${`.
  - `value`: dynamicString; required.

- `length` returns validationResult. Checks string length constraints.
  - `max`: literal; optional. The maximum allowed length.
  - `min`: literal; optional. The minimum allowed length.
  - `value`: dynamicString; required.

- `not` returns boolean. Performs a logical NOT operation on a boolean value.
  - `value`: dynamicBoolean; required. The boolean value to negate.

- `numeric` returns validationResult. Checks numeric range constraints.
  - `max`: literal; optional. The maximum allowed value.
  - `min`: literal; optional. The minimum allowed value.
  - `value`: dynamicNumber; required.

- `openUrl` returns void. Opens the specified URL in a browser or handler (requires user activation). This function has no return value.
  - `url`: literal; required. The URL to open.

- `or` returns boolean. Performs a logical OR operation on a list of boolean values.
  - `values`: arrayOfDynamicValues; required. The list of boolean values to evaluate.

- `pluralize` returns string. Returns a localized string based on the Common Locale Data Repository (CLDR) plural category of the count (zero, one, two, few, many, other). Requires an 'other' fallback. For English, just use 'one' and 'other'.
  - `few`: dynamicString; optional. String for the 'few' category (e.g., small groups in Slavic languages).
  - `many`: dynamicString; optional. String for the 'many' category (e.g., large groups in various languages).
  - `one`: dynamicString; optional. String for the 'one' category (e.g., 1 item).
  - `other`: dynamicString; required. The default/fallback string (used for general plural cases).
  - `two`: dynamicString; optional. String for the 'two' category (used in Arabic, Welsh, etc.).
  - `value`: dynamicNumber; required. The numeric value used to determine the plural category.
  - `zero`: dynamicString; optional. String for the 'zero' category (e.g., 0 items).

- `regex` returns validationResult. Checks that the value matches a regular expression string.
  - `pattern`: literal; required. The regular expression to search for in the value. Uses the A2UI regex dialect: a portable subset of ECMAScript pattern syntax in Unicode mode with no flags. Matching is case-sensitive, '.' excludes line terminators, and '^' and '$' match only at the ends of the value. Backreferences, lookbehind, named groups and '\p{...}' are not allowed. Patterns longer than 256 code points or that could backtrack catastrophically are rejected.
  - `value`: dynamicString; required.

- `required` returns validationResult. Checks that the value is not null, undefined, or empty.
  - `value`: dynamicValue; required. The value to check.

## Actions

Only these action names may appear in an event. No other action names are allowed. Context values may be literals or data bindings.
- `submit_signup`: Submit the sign-up form. Carries the name entered in the form. Context: {"name":{"@path":"/form/name"}}.

## Examples

### Simple card
```jsonl
{"createSurface":{"catalogId":"https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json","surfaceId":"notice"},"version":"1.0"}
{"updateComponents":{"components":[{"child":"message","component":"Card","id":"root"},{"component":"Text","id":"message","text":"## Your order has shipped."}],"surfaceId":"notice"},"version":"1.0"}
```

### Form with a bound field and a button action
```jsonl
{"createSurface":{"catalogId":"https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json","surfaceId":"signup"},"version":"1.0"}
{"updateDataModel":{"path":"/form/name","surfaceId":"signup","value":""},"version":"1.0"}
{"updateComponents":{"components":[{"children":["name_field","submit"],"component":"Column","id":"root"},{"component":"TextField","id":"name_field","label":"Name","value":{"@path":"/form/name"}},{"action":{"event":{"context":{"name":{"@path":"/form/name"}},"name":"submit_signup"}},"child":"submit_label","component":"Button","id":"submit","variant":"primary"},{"component":"Text","id":"submit_label","text":"Sign up"}],"surfaceId":"signup"},"version":"1.0"}
```

### Edit mode: change one value with updateDataModel
```jsonl
{"createSurface":{"catalogId":"https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json","surfaceId":"order"},"version":"1.0"}
{"updateComponents":{"components":[{"component":"Text","id":"root","text":{"@path":"/status"}}],"surfaceId":"order"},"version":"1.0"}
{"updateDataModel":{"path":"/status","surfaceId":"order","value":"Packed"},"version":"1.0"}
{"updateDataModel":{"path":"/status","surfaceId":"order","value":"Shipped"},"version":"1.0"}
```
