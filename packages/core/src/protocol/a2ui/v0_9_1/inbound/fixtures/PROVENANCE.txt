The production representation is generated from the pinned catalog.json and
common_types.json by scripts/generate-basic-catalog.mjs. It is not an exact
copy: Weaver inlines the upstream common_types resource and flattens the
catalog component `allOf` composition into a single self-contained catalog
document, rewriting absolute and local common-types references to
`common_types.json#/$defs/...`. FunctionCall's function-contract restriction
is preserved by rewriting the original cross-document
`catalog.json#/$defs/anyFunction` reference to the generated nested
`basic_functions.json#/$defs/anyFunction`, which contains the copied/normalized
canonical Basic function contracts and anyFunction union. This normalization
is required so CatalogRegistry can compile the canonical catalog through its
existing self-contained-document reference handling without runtime fetching.
