# Weaver Framework Plan

Weaver is being developed as an independent interface runtime framework. The
detailed development plan remains in `weaver-dev-plan.md`; this bootstrap phase
only establishes the workspace and package boundaries.

## Current phase

- Establish `@weaver/core`, `@weaver/web`, and `@weaver/mcp` boundaries.
- Prove workspace consumption through a framework-free Vite playground.
- Preserve the prototype unchanged as input to later design work.

## Deferred work

- A2UI message types and runtime behavior.
- MCP SDK selection and integration.
- Migration and redesign of prototype behavior.
- Zynra V2 application integration.
